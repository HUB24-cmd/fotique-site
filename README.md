# Fotique website

Website van Fotique: photobooth en 360° videobooth huren in de Randstad. Live op https://fotique.nl.

- `index.html` is de hele site (teksten, prijzen, pakketten, boekingsformulier, NL/EN).
- `media/` bevat de foto's en video's.

Netlify zet elke push naar `main` automatisch live.
